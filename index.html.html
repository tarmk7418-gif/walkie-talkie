✅ 유지비 0원(평생 무료) 아키텍처 구성

이 앱은 단일 HTML 파일과 브라우저 내장 Web Audio/Speech API를 활용하므로 별도의 고가 음성 서버나 유료 STT API 결제가 전혀 필요 없습니다.

1단계: 무료 웹 호스팅 배포 (1분 완료)

  • Vercel 또는 GitHub Pages: 현재 HTML 파일을 index.html로 저장해 업로드하면 무료 HTTPS 도메인이 즉시 발급됩니다. (마이크 권한은 HTTPS 환경에서 자동 활성화)

2단계: 실시간 다자간 동기화 무료 연결

  • Firebase Spark(무료) 플랜: 일일 5만 건 읽기 / 2만 건 쓰기가 무료로 제공되어 소규모 모임이나 매장 스태프 무전용으로 비용 없이 운영 가능합니다.
  • 같은 브라우저에서 여러 탭을 열면 BroadcastChannel을 통해 오프라인 상태에서도 즉시 탭 간 무전 동기화를 테스트할 수 있습니다.

3단계: 스마트폰 홈 화면에 앱(PWA)처럼 설치

  • iOS (Safari): 하단 공유 버튼() → [홈 화면에 추가] 선택
  • Android (Chrome): 우측 상단 메뉴(⋮) → [홈 화면에 추가 / 앱 설치] 선택
